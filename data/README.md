# Data directories

- `templates/fii_canonical_input_template.csv` is the minimal blank input
  template. Add optional fields only when they are available.
- `synthetic_example/fii_synthetic_example.csv` is deterministic, fictional,
  and generated by `scripts/generate_synthetic_data.py`.

The synthetic values were not sampled, perturbed, fitted, or reconstructed
from restricted measurements. They demonstrate software execution only and
cannot reproduce restricted reference-analysis results. See `../DATA_SCHEMA.md` for
the full contract.
